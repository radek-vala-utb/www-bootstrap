6. Branding

Vlastní barvy a theming

Nejefektivnější způsob v Bootstrapu 5 je přepsat CSS proměnné. Tím změníš tlačítka, odkazy i další komponenty bez ručního přepisování každého prvku.

Globální override přes `:root`

Pokud chceš změnit základní brand barvy celé stránky, přepiš Bootstrap proměnné v `:root`. Třídy jako `text-primary` nebo `link-primary` pak začnou používat nové hodnoty. U tlačítek je navíc potřeba přepsat i jejich vlastní `--bs-btn-*` proměnné.

CSS ukázka

:root {
  --bs-primary: #d73800;
  --bs-primary-rgb: 215, 56, 0;
  --bs-secondary: #555555;
  --bs-secondary-rgb: 85, 85, 85;
  --bs-link-color: #d73800;
  --bs-link-hover-color: #ad2d00;
  --brand-primary-hover: #ad2d00;
  --brand-primary-active: #922600;
  --brand-secondary-hover: #444444;
  --brand-secondary-active: #383838;

}

.btn-primary {
  --bs-btn-bg: var(--bs-primary);
  --bs-btn-border-color: var(--bs-primary);
  --bs-btn-hover-bg: var(--brand-primary-hover);
  --bs-btn-hover-border-color: var(--brand-primary-hover);
}

.btn-secondary {
  --bs-btn-bg: var(--bs-secondary);
  --bs-btn-border-color: var(--bs-secondary);
  --bs-btn-hover-bg: var(--brand-secondary-hover);
  --bs-btn-hover-border-color: var(--brand-secondary-hover);
}

Lokální override jen pro jednu sekci

Když nechceš přebarvit celý web, obal si konkrétní blok vlastní třídou a přepiš proměnné jen tam.

Sekce s lokální značkou

Uvnitř tohoto bloku používají `text-primary`, `btn-primary` i `badge` nové lokální barvy.

badge success

`.brand-scope`

Přepisuje `--bs-primary`, `--bs-success` a `--bs-border-color` jen pro vnořené prvky.

CSS ukázka

.brand-scope {
  --bs-primary: #8b1e3f;
  --bs-primary-rgb: 139, 30, 63;
  --bs-success: #2d6a4f;
  --bs-success-rgb: 45, 106, 79;
  --bs-border-color: #e7c9d3;
  --brand-primary-hover: #6f1832;
  --brand-primary-active: #571227;
}

Praktické doporučení

  • Nejrychlejší override je přes CSS proměnné `--bs-*`, ne přes ruční přepis každé komponenty.
  • Při změně barvy uprav i odpovídající `-rgb` proměnnou, protože ji Bootstrap používá ve stavech a průhlednostech.
  • Globální změny patří do `:root`, lokální témata do obalové třídy typu `.brand-scope`.
  • Pro větší projekt je další krok Sass build, ale pro výuku a menší web bohatě stačí CSS variables.
